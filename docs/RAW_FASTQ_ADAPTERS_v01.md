# Raw FASTQ adapter draft

Generic RNA trimming/STAR alignment and ATAC alignment/deduplication/filtering/MACS3 processes are implemented in modules/raw.nf and wired into raw_prepare and process_fastq entry. All four single-end RNA FASTQs passed exact sequence/count/TPM/primary-DE regression; synthetic paired geometry passed. Actual ATAC equivalence remains under investigation. The pilot stage emits alignment/peak checkpoints and does not by itself establish downstream scientific completion. All geometry comes from the paired field, with one ordered FASTQ for FALSE and two for TRUE.

Historical RNA logs establish Cutadapt 4.8 with Python 3.9.18, quality threshold 20, minimum length 20 and the six saved adapter sequences. The current shared-system interpreter has advanced to Python 3.9.21. A separately pinned Python 3.9.18 Linux image passed native version/platform checks; v05/v06 snapshot the module payloads, qualify Picard duplicate removal and support Nextflow metrics. v06 qualifies the four-library RNA and paired-geometry runs. v07 additionally isolates header-authenticated samtools/htslib 1.20 for raw ATAC alignment.

STAR uses the historical twopassMode Basic, coordinate-sorted BAM output and 20-GB BAM sort limit. The preserved 60-bp index corresponds to sjdbOverhang=59. A prebuilt index is an explicit reference input; the draft does not rebuild it silently.

ATAC uses Bowtie2 2.5.3 --very-sensitive, Picard 3.1.1 with OpenJDK 21.0.2, duplicate removal, MAPQ≥10 and unmapped-read exclusion. Contig exclusions are explicit parameters. The historical fixture uses the literal chrM substring filter; a distinct RNAME mode retains SAM headers and excludes exact contigs. The differences must remain labelled rather than silently modifying the original filtering method.

The original BAM's program records establish samtools 1.20 and default single-thread sorting for this alignment. The current supplied script's 1.22.1 declaration does not authenticate that earlier stage. The first v06 pilot differs slightly in window counts; v07/source_v17 tests the recovered original settings separately. Later blacklist processing retains 1.22.1. See ATAC_ALIGNMENT_PROVENANCE_v01.md.

The post-blacklist peak caller uses MACS3 3.0.1 and q=0.05. Single-end data uses --nomodel --shift -100 --extsize 200; paired-end data uses BAMPE. Effective genome size is required explicitly for new datasets. BAM/peak checkpoint routes retain the provided peaks; they do not silently overwrite them by recalling peaks.

The user authorized a standard diffHic candidate for paired Hi-C. The explicit diffhic_presplit_standard_compat route emits a name-sorted, mate-synchronized, duplicate-marked BAM through modules/hic_raw.nf. Its eight-pair native synthetic test verifies all primary 5-prime coordinates and seven hard-clipped secondary segments. Exact custom _t32 equivalence remains unknown. See HIC_STANDARD_PRESPLIT_AND_ARIMA_v01.md for every adapter change, pinned runtime and the separate future cocktail-library protocol.
